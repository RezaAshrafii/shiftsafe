# فاز ۳ — baseline و معیارهای پایه

## چرا قبل از مدل اصلی baseline لازم است؟

ممکن است یک مدل پیچیده عدد خوبی نشان دهد، اما همان عدد با یک پیش‌بینی بسیار ساده هم به‌دست بیاید. baseline پاسخ می‌دهد: «آیا اصلاً مدل ارزش اضافه کردن دارد؟» بدون این مقایسه، ادعای پیشرفت پژوهشی یا تجاری قابل دفاع نیست.

## چه چیزی ساخته شد؟

### baseline رگرسیون

میانگین target در داده آموزش محاسبه می‌شود و برای همه نمونه‌های آزمون همان مقدار پیش‌بینی می‌شود. این روش ساده است، اما یک خط پایه روشن برای خطا می‌سازد.

### baseline طبقه‌بندی

پرتکرارترین کلاس داده آموزش برای همه نمونه‌ها انتخاب می‌شود. در صورت مساوی بودن کلاس‌ها، انتخاب به‌صورت قطعی انجام می‌شود تا اجرای دوباره نتیجه متفاوت ندهد.

## معیارها

- `MAE`: میانگین قدرمطلق خطا؛ به زبان ساده، به‌طور متوسط چقدر از مقدار واقعی فاصله داریم.
- `RMSE`: خطاهای بزرگ را بیشتر جریمه می‌کند؛ برای خطاهای شدید مفید است.
- `accuracy`: چند درصد پیش‌بینی‌ها درست بوده‌اند.
- `balanced_accuracy`: recall هر کلاس را جدا حساب و میانگین می‌گیرد؛ برای کلاس‌های نامتوازن منصفانه‌تر از accuracy ساده است.

## نکته مهم درباره target تک‌مقداری

اگر target فقط یک مقدار داشته باشد، baseline هنوز قابل محاسبه است؛ اما این به معنی وجود یک مسئله یادگیری ارزشمند نیست. در این نسخه ادعای مدل یا ارزش کسب‌وکاری از روی چنین داده‌ای صادر نمی‌شود.

## تست‌ها

تست‌ها خروجی عددی رگرسیون، accuracy و balanced accuracy، انتخاب کلاس پرتکرار و ورودی خالی را بررسی می‌کنند. هیچ وابستگی جدیدی اضافه نشده و محاسبات با pandas و کتابخانه استاندارد انجام می‌شود.

## محدودیت فاز

هنوز مدل واقعی، تنظیم ابرپارامتر، uncertainty، calibration یا تحلیل shift نداریم. این فاز فقط یک کف قابل اندازه‌گیری می‌سازد تا فازهای بعدی صادقانه مقایسه شوند.

## توضیح شفاهی آماده

«قبل از ساخت مدل، دو baseline ساختم: در رگرسیون میانگین آموزش و در طبقه‌بندی کلاس پرتکرار. سپس MAE و RMSE یا accuracy و balanced accuracy را حساب می‌کنم. اگر مدل بعدی از این کف ساده بهتر نشود، دلیلی برای پیچیده‌تر کردن محصول یا ادعای پژوهشی نداریم.»
