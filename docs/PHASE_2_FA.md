# فاز ۲ — تفکیک داده بدون نشت اطلاعات

این سند توضیح می‌دهد در فاز دوم چه چیزی ساخته شده و چرا برای یک پروژه پژوهشی و تجاری قابل اعتماد مهم است.

## مسئله‌ای که حل کردیم

اگر بخشی از داده‌های آینده یا بخشی از یک گروه مشترک هم‌زمان در آموزش و آزمون قرار بگیرد، نتیجه مدل مصنوعی خوب به نظر می‌رسد. به این خطا «نشت داده» می‌گوییم. در کاربرد واقعی، مدل باید روی آینده یا یک گروه جدید کار کند؛ بنابراین ارزیابی باید همین شرایط را شبیه‌سازی کند.

## دو روش موجود

### ۱. تفکیک زمانی (`temporal_split`)

این روش فرض می‌کند داده‌ها به ترتیب زمان هستند:

1. ستون زمان بررسی می‌شود.
2. تاریخ‌های غیرقابل‌خواندن رد می‌شوند.
3. اگر ردیف‌ها از قبل صعودی نباشند، برنامه خطا می‌دهد و بی‌صدا آن‌ها را جابه‌جا نمی‌کند.
4. ردیف‌های قدیمی‌تر در train و جدیدترین ردیف‌ها در test قرار می‌گیرند.

مثال: اگر ۸۰ درصد اول برای آموزش و ۲۰ درصد آخر برای آزمون باشد، مدل اجازه ندارد از آینده برای یادگیری استفاده کند.

### ۲. تفکیک گروهی (`group_split`)

گاهی هر ردیف به یک بیمار، کارخانه، مشتری یا سایت تعلق دارد. اگر ردیف‌های یک سایت در هر دو بخش باشند، مدل ممکن است هویت همان سایت را حفظ کند و نتیجه غیرواقعی شود.

در این روش:

1. ستون گروه و مقدارهای خالی بررسی می‌شوند.
2. گروه‌ها به‌صورت قطعی مرتب می‌شوند.
3. چند گروه کامل برای test کنار گذاشته می‌شوند.
4. هیچ گروهی بین train و test مشترک نیست.

## خطاهای قابل فهم

به‌جای خطای مبهم، کد خطاهایی مثل `time_column_missing`، `test_fraction_must_be_between_0_and_1` و `group_column_contains_missing_values` برمی‌گرداند. این کار برای گزارش‌دهی به استاد، شرکت یا API آینده مهم است.

## چه تست‌هایی نوشته شد؟

تست‌ها این موارد را پوشش می‌دهند:

- جدا شدن آینده از گذشته؛
- رد شدن ستون زمان ناموجود؛
- رد شدن زمان نامرتب؛
- جلوگیری از اشتراک گروه‌ها؛
- رد شدن نسبت آزمون نامعتبر؛
- رد شدن ورودی خالی.

## محدودیت صادقانه این فاز

این فاز هنوز مدل یادگیری ماشین، فاصله عدم‌قطعیت، تشخیص تغییر توزیع یا داشبورد ندارد. همچنین تفکیک گروهی در این نسخه تصادفی نیست و برای تکرارپذیری به‌صورت قطعی انجام می‌شود؛ برای داده‌های نامتوازن، در فازهای بعدی باید روش‌های تخصصی‌تر بررسی شوند.

## توضیح شفاهی آماده

«در فاز دوم، قبل از آموزش هر مدل، مرز ارزیابی را ایمن کردم. برای داده زمانی فقط گذشته وارد آموزش می‌شود و آینده برای آزمون می‌ماند. برای داده گروهی، کل یک بیمار یا سایت فقط در یکی از دو بخش قرار می‌گیرد. اگر زمان نامرتب، ستون ناقص یا نسبت نامعتبر باشد، برنامه ادامه نمی‌دهد و خطای قابل فهم گزارش می‌کند. بنابراین عدد دقت مدل دیگر به‌خاطر نشت ساده داده قابل اعتماد کاذب نیست.»
