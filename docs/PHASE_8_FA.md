# فاز ۸ — abstention و تصمیم اعتمادپذیری

## مسئله

مدل نباید همیشه مجبور باشد پاسخ قطعی بدهد. اگر interval خیلی پهن باشد، یعنی عدم‌قطعیت بالا است و بهتر است نمونه برای بررسی بیشتر علامت‌گذاری شود.

## منطق فعلی

یک threshold به نام `max_width` وارد می‌کنیم:

```text
width <= max_width  → TRUST
width > max_width   → ABSTAIN
```

برای هر ردیف این موارد ثبت می‌شود:

- پهنای interval؛
- تصمیم `TRUST` یا `ABSTAIN`؛
- دلیل تصمیم.

## خلاصه‌ی خروجی

سیستم نرخ این موارد را محاسبه می‌کند:

- تعداد کل ردیف‌ها؛
- تعداد trusted؛
- تعداد abstained؛
- trust rate؛
- abstention rate.

## محدودیت مهم

threshold فعلی یک policy input است و هنوز از هزینه‌ی واقعی شرکت، false alarm، missed event یا زمان بررسی انسانی استخراج نشده است. بنابراین `TRUST` به معنی تضمین ایمنی یا صحت نیست؛ فقط یعنی width از threshold انتخاب‌شده کمتر یا مساوی است.

## توضیح شفاهی آماده

«در فاز هشت، مدل را مجبور نکردم برای همه‌ی نمونه‌ها پاسخ قطعی بدهد. اگر پهنای prediction interval از threshold بیشتر باشد، سیستم `ABSTAIN` می‌دهد و نمونه را برای بررسی انسانی یا داده‌ی بیشتر علامت می‌زند. نرخ اعتماد و نرخ abstention گزارش می‌شوند. threshold فعلاً یک پارامتر سیاستی است و تا زمان داشتن هزینه‌های واقعی شرکت، ادعای اقتصادی از آن نداریم.»
